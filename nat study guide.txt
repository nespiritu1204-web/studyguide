    <h1>MATH 11 Study Guide</h1>
    <p class="subtitle">Confidence Intervals · Hypothesis Tests · Two-Sample Tests · Matched Pairs · ANOVA · Chi-Square</p>

    <div class="card">
      <div class="tag">Confidence Intervals</div>
      <h2>1. Confidence Intervals (CI)</h2>

      <h3>1.1 CI for One Mean (σ unknown)</h3>
      <p class="mini-heading">Formula:</p>
      <pre>CI = x̄ ± t* · ( s / √n )</pre>
      <p class="mini-heading">Where:</p>
      <ul>
        <li>x̄ = sample mean</li>
        <li>s = sample standard deviation</li>
        <li>n = sample size</li>
        <li>t* = critical t-value</li>
      </ul>

      <h3>1.2 CI for One Proportion</h3>
      <p class="mini-heading">Formula:</p>
      <pre>CI = p̂ ± z* · √( p̂(1 − p̂) / n )</pre>
      <p class="mini-heading">Where:</p>
      <ul>
        <li>p̂ = x / n = sample proportion</li>
        <li>z* = critical z-value (1.96 for 95%, etc.)</li>
      </ul>
    </div>

    <div class="card">
      <div class="tag">1-Sample Tests</div>
      <h2>2. One-Sample Hypothesis Tests</h2>

      <h3>2.1 Test for a Mean</h3>
      <p class="mini-heading">Test statistic:</p>
      <pre>t = ( x̄ − μ₀ ) / ( s / √n )</pre>

      <h3>2.2 Test for a Proportion</h3>
      <p class="mini-heading">Test statistic:</p>
      <pre>z = ( p̂ − p₀ ) / √( p₀(1 − p₀) / n )</pre>
    </div>

    <div class="card">
      <div class="tag">Two-Sample</div>
      <h2>3. Two-Sample Procedures</h2>

      <h3>3.1 Two Independent Means</h3>
      <p class="mini-heading">Standard error:</p>
      <pre>SE = √( s₁² / n₁ + s₂² / n₂ )</pre>
      <p class="mini-heading">CI for μ₁ − μ₂:</p>
      <pre>CI = ( x̄₁ − x̄₂ ) ± t* · SE</pre>

      <h3>3.2 Two Proportions</h3>
      <p class="mini-heading">Pooled proportion (for tests):</p>
      <pre>p pooled = ( x₁ + x₂ ) / ( n₁ + n₂ )</pre>
      <p class="mini-heading">Test statistic:</p>
      <pre>z = ( p̂₁ − p̂₂ )
    / √( p pooled (1 − p pooled)(1/n₁ + 1/n₂) )</pre>
    </div>

    <div class="card">
      <div class="tag">Matched Pairs</div>
      <h2>4. Matched Pairs (Paired Data)</h2>
      <p>Define differences: d = after − before.</p>
      <p class="mini-heading">CI:</p>
      <pre>CI = d̄ ± t* · ( s_d / √n )</pre>
      <p class="mini-heading">Test statistic:</p>
      <pre>t = d̄ / ( s_d / √n )</pre>
    </div>

    <div class="card">
      <div class="tag">ANOVA</div>
      <h2>5. ANOVA (Analysis of Variance)</h2>
      <p class="mini-heading">Test statistic:</p>
      <pre>F = MS_between / MS_within</pre>
      <p>If F is large and p-value &lt; α, reject H₀: not all means are equal.</p>
    </div>

    <div class="card">
      <div class="tag">Chi-Square</div>
      <h2>6. Chi-Square Tests</h2>

      <h3>6.1 Goodness of Fit</h3>
      <p class="mini-heading">Statistic:</p>
      <pre>χ² = Σ (O − E)² / E</pre>

      <h3>6.2 Independence (Two-Way Table)</h3>
      <p class="mini-heading">Expected count in cell (i, j):</p>
      <pre>Eᵢⱼ = ( row totalᵢ · column totalⱼ ) / grand total</pre>
      <p class="mini-heading">Statistic:</p>
      <pre>χ² = Σ (Oᵢⱼ − Eᵢⱼ)² / Eᵢⱼ</pre>
    </div>

    <div class="cheat">
      <div class="tag">Cheat Sheet</div>
      <h2>7. Quick Cheat Sheet</h2>
      <pre>One mean:
CI: x̄ ± t* · ( s / √n )
t : ( x̄ − μ₀ ) / ( s / √n )

One proportion:
CI: p̂ ± z* · √( p̂(1 − p̂) / n )
z : ( p̂ − p₀ ) / √( p₀(1 − p₀) / n )

Two means:
CI: ( x̄₁ − x̄₂ ) ± t* · √( s₁²/n₁ + s₂²/n₂ )

Two proportions:
z : ( p̂₁ − p̂₂ ) / √( p pooled(1 − p pooled)(1/n₁ + 1/n₂) )

Matched pairs:
CI: d̄ ± t* · ( s_d / √n )
t : d̄ / ( s_d / √n )

ANOVA:
F = MS_between / MS_within

Chi-square:
χ² = Σ (O − E)² / E</pre>
    </div>
